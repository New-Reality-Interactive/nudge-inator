# 02: As-built mockup

**What to build:** A mockup that matches the app as it is today, so there is a true record of the shipped design to propose changes against. It is an HTML copy of the first-version mockup, changed wherever the built app differs, and checked screen by screen against simulator screenshots. The first-version mockup moves to the mockup archive, its README saying it is superseded by this one. Spec stories 1 and 2.

**Blocked by:** 01 (the screenshots come from its simulators).

**Status:** ready-for-agent

- [ ] The as-built mockup is a single HTML file with a README, in a dated folder under the mockups, opening in a browser with no dependencies, as the first-version one does.
- [ ] Every screen in the app (Now, My Day, Tags and a tag's list, Settings, the reminder form and its pages, reminder details, How It Nudges, onboarding, the permission banners) appears in it and matches simulator screenshots from both the 26.5 and 27.x simulators in portrait, landscape and a large text size.
- [ ] The README lists each difference from the first-version mockup that was found and corrected.
- [ ] The screenshots used for the check are kept with it, or the README says where they are and how to make them again.
- [ ] The first-version mockup is in the archive, its README marked superseded with a link to this one, and links to it elsewhere (README, DESIGN.md, the first-version spec) point to its new place.
- [ ] Brian has looked it over and agrees it matches the app.
