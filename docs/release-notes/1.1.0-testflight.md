# 1.1.0 TestFlight: What to Test

Paste the text below into the build's **What to Test** in App Store Connect when uploading 1.1.0
(spec story 48). TestFlight shows it to the testers before they install, and it's plain text, so
the block is written without Markdown.

```text
Before you install this version:

1. Open Nudge-inator, go to Settings, tap Delete All Data, then Delete. This cancels every nudge and alarm. Deleting the app alone leaves its alarms behind.
2. Delete Nudge-inator from your iPhone.
3. Install this version from TestFlight.

Your reminders from the last version don't carry over, so you start fresh with no leftover alarms.

What's new: each reminder now has a pace. Consistent nudges at one steady wait you choose, from 2 min to 16 hr. Escalating nudges more and more often, as before. Settings › Default Pace sets the pace every new reminder starts with: Consistent · 10 min unless you change it.
```
