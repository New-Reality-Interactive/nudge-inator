Nudge-inator accent candidates

The spine stays semantic; pick one (or ask for a blend). The accent means only "you can tap this". Status colors (red, orange, green, indigo, gray) are fixed.

Contrast is WCAG 2 ratio, measured with a script. Tab pill is composited as described in the brief. ΔE2000 below 25 is shown in orange as "risky". Light-mode accents sit near the neutral gray in ΔE because both must reach about 4.5:1 on the same background; the difference there is hue/chroma (gray is achromatic), not lightness. Lock Screen Snooze always uses the dark variant.
