# Nudge-inator iOS mockup: tutorial pills on one line

A change mockup for `enhancement-alarm-sound` (spec #129), from #470's phone check (2026-11-20).
Copied from the [How It Nudges strength pills mockup](../2026-11-20-how-it-nudges-strength-pills/README.md),
with #467's approved [How Alarm Sounds Work leads](../2026-11-20-alarm-sounds-tutorial-leads/README.md)
brought in, and only this changed, so the screens can be compared. The 1.5.0 version mockup takes it
in and replaces it.

Open [`index.html`](index.html) in a browser. The panel's **Tutorials (#465)** group opens each sheet;
the text size control shows the largest sizes.

## What changed

- **Every tutorial's pills** (How It Nudges, How Sharing Works, How Alarm Sounds Work), as How Alarm
  Sounds Work's Change Your Reminders already did: each pill keeps its words on one line, so no pill
  wraps (as Connect's Invite and Connected did) or crowds its edges, and its text stops growing at
  the largest standard size (xxxLarge). Each pill is as wide as its own words, and every pill on a
  page has the same text size. Where they don't fit side by side, they stack, with the arrow
  pointing down.

Nothing else changed.
