# Nudge-inator iOS mockup: Delete All Data covers sharing

The change mockup for Delete All Data's confirmation (#214, spec #127, version 1.4.0), copied from the
[sharing privacy copy mockup](../2026-11-13-sharing-footer-copy/README.md), the latest of the feature's
change mockups. It's deleted when the 1.4.0 version mockup takes the change in.

Open [`index.html`](index.html) in a browser, then Settings, Delete All Data.

## What changed since the sharing privacy copy mockup

- Delete All Data's confirmation adds "It also disconnects everyone and deletes the reminders you've
  sent and received, here and in iCloud." only while a connection is connected or an invite is open.
  With none (or only a connection the other person ended), it reads as it did before sharing.
- To see both: Reset the mockup, open Delete All Data (with connections), then delete everything and
  open it again.
