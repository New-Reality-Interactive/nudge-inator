# Nudge-inator iOS mockup: Send With icons

A proposal for #217's invite flow, copied from the
[Delete All Data mockup](../2026-11-13-delete-all-data-sharing/README.md), the latest of the
feature's change mockups. It is not built: it shows what the app could draw itself instead of
`UICloudSharingController`'s screens, for the developer to compare. It is deleted if not taken in.

Open [`index.html`](index.html) in a browser, then Settings › Connections › Invite Someone (Invite Again too).

## What changed since the custom invite screen mockup

The change mockup for a small change to Invite Someone (#217), copied from the
[custom invite screen mockup](../2026-11-13-custom-invite-screen/README.md), approved on 2026-11-13.
It is deleted when the 1.4.0 version mockup takes the change in.

- Each way in **Send With** now has an icon before its name, in the tint color: a speech bubble for
  Messages (`message`), an envelope for Mail (`envelope`), a link for Copy Link (`link`). The check
  mark on the selected way stays at the right. Nothing else changed.
